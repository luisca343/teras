# Teras

Teras is a comprehensive Minecraft Forge mod for version 1.16.5 that enhances gameplay with various features, with a special focus on kart racing. The mod integrates with several popular Minecraft mods like Pixelmon, MrCrayfish's Vehicle Mod, and others to create a rich gaming experience.

## 🏁 Kart Racing System

The heart of this mod is its fully-featured kart racing system, allowing players to compete in races around custom tracks.

### Features:
- **Race Tracks with Checkpoints**: Create and use custom race tracks with strategic checkpoints
- **Multiplayer Racing**: Join races with other players and compete for the best time
- **Voting System**: Players can vote to start races when enough participants are ready
- **Countdown and Race Management**: Enjoy a professional racing experience with countdown timers
- **Position Tracking**: Real-time updates of your position in the race
- **Lap Counting**: Race for multiple laps with automatic lap tracking

## 🧩 Additional Features
- **Pixelmon Integration**: Custom battle controllers and attacks for Pixelmon
- **Voice Chat Support**: Integrated voice chat functionality
- **Custom Fluids**: New fluids including thermal waters
- **Custom Blocks and Items**: New content to enhance gameplay
- **Browser Integration**: In-game web browser capabilities through MCEF
- **Custom NPCs Compatibility**: Works with Custom NPCs mod

## ⚙️ Installation
1. Install Minecraft Forge for version 1.16.5
2. Download and install all required dependencies/mods
3. Place the Teras mod JAR file in your Minecraft mods folder
4. Launch Minecraft with Forge

## 📋 Requirements
- Minecraft 1.16.5
- Forge 36.2.39+

### Required Mods
- MrCrayfish's Vehicle Mod
- Pixelmon
- MCEF (Minecraft Chromium Embedded Framework)
- Simple Voice Chat
- Custom NPCs

## 🎮 Usage

### Kart Racing Commands
- Join a race: `/karts join [track] [laps]`
- Leave a race: `/karts salir`
- Vote to start a race: `/karts votar`
- Cancel your vote: `/karts cancelarvoto`
- List available tracks: `/karts list`
