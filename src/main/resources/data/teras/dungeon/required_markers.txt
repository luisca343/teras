# Which markers a room key must carry, read by BOTH audits.
#
# There are two: RoomAudit, which runs when a room is saved in the in-game editor, and the Python
# room tool, which runs when the shipped templates are generated. They were hand-maintained mirrors
# of each other, and they drifted the first time it mattered — §37 added `loot` to secret rooms in
# the tool and not in Java, so a secret authored in game still shipped with no pedestal and paid
# nothing. This file is what they both read instead.
#
# Format: <roomKey>: <marker>[, <marker>...]     '#' starts a comment.
# A marker named here must be one the runtime actually READS — see MarkerContract, which refuses
# to let an annotation be required.

# Both boss keys owe the boss stand. Listed twice rather than matched by prefix, so the table stays
# a lookup with no logic in it and neither reader has to reimplement the rule. The trapdoor moved
# to the exit room (la sala del sello); a boss template may still carry one, and it is what the
# fallback carve uses on a piso that has no exit template.
boss:         boss
boss_big:     boss

# La sala del sello: the pit down, the boss reward stand, and where the ascensor is stamped on the
# floor that closes a tramo. Optional key — a piso without one falls back to carving the pit in the
# arena — but a shipped exit room owes all three. `ascensor` marks a position, not a structure: the
# fixture is pasted there only on a tramo boundary, so a piso that omits the marker silently loses
# every lift it should have had.
exit:         trapdoor, premio, ascensor

mini_boss:    boss
treasure:     loot

# A secret costs a wall charge the party bought, so it has to pay out where its pedestal stands.
secret:       loot
super_secret: loot

shop:         shopslot

# The curse room is a market, not a payout: its offers stand on `oferta` and the stand that buys an
# affliction back on `purga`. It owes no `loot` — everything inside it is traded for, and the price
# of entry is a heart taken at the spiked doorway.
curse:        oferta, purga

sacrifice:    sacrifice
arcade:       arcade
devil_deal:   deal

# La sala de la Orden, the other flank of the sello. Optional like `exit` — a piso without one never
# offers grace and the Acreedor's half of the arc still runs — but a shipped one owes the font she
# stands at, which is where her gift is claimed.
orden:        gracia

# The challenge plate is where the fight starts, so its marker is load-bearing on top of the waves.
challenge:    spawn, challenge

# Where the party lands. Without it arrival falls back to the room's centre, which is only safe
# while that centre happens to be empty floor — a start chamber built around any central feature
# teleports the party inside it.
start:        inicio

# Every normal room, whatever its footprint — keys carry the shape family, never the orientation.
normal:       spawn
normal_large: spawn
normal_l:     spawn
normal_big:   spawn
